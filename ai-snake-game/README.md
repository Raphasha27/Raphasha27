# 🐍 AI Snake Game — Autonomous Showcase Edition

## 🚀 Project Overview
This project is an elite autonomous Snake Game built to demonstrate advanced game logic, AI-driven movement, and real-time rendering. Unlike a basic snake clone, this version is designed to:
- **Play automatically** (AI-controlled)
- **Run at high difficulty**
- **Showcase clean architecture** and professional coding standards
- **Serve as a portfolio-quality demonstration** of logic, performance, and animation

Inspired by classic arcade mechanics and modern system design principles.

- ✅ **Real-time rendering loop**

- **AI Logic**: BFS (Breadth-First Search) / Heuristic-based pathfinding

## 🧪 AI Snake Logic
1.  **Pathfinding**: The snake calculates the shortest path to the food using BFS.
2.  **Safety Check**: If a direct path to food puts the snake in a dead end (trapped by its own body), it switches to "Survival Mode".
3.  **Survival Mode**: The snake attempts to find the longest path available (e.g., following its tail) to stall until space opens up.
4.  **Execution**: The game loop runs at 60fps, with logic updates throttled for visual clarity.
