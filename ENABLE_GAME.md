# 🎮 How to Enable Your Pacman Game

GitHub Pages is currently **disabled**, which is why you see a 404 error. 

### ⚡ 30-Second Fix:

1. Go to your repository settings:  
   👉 **[https://github.com/Raphasha27/Raphasha27/settings/pages](https://github.com/Raphasha27/Raphasha27/settings/pages)**

2. Under **"Build and deployment"** > **"Branch"**:
   - Change the dropdown from `None` to **`main`**.
   - Ensure the folder is set to **`/(root)`**.
   - Click **Save**.

3. ⏳ **Wait 1 minute**.
   - Refresh the page until you see a green bar saying "Your site is live at..."

4. 🚀 **Play your Game**:
   - **[Click Here to Play Pacman](https://raphasha27.github.io/Raphasha27/pacman_game.html)**

---
*Once you do this, the "PLAY LIVE" button in your profile README will work automatically!*
