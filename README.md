## 📦 SupplyWave SA — Logistics Architecture

```mermaid
sequenceDiagram
    participant Client as 🏢 B2B Client
    participant API as ⚡ FastAPI Gateway
    participant GeoEngine as 🗺️ PostGIS GeoEngine
    participant AI as 🤖 Route Optimizer (TSP)
    participant DB as 🗄️ PostgreSQL

    Client->>API: POST /api/route/optimize
    API->>GeoEngine: Fetch depot & delivery coordinates
    GeoEngine->>DB: Query spatial carrier nodes
    DB-->>GeoEngine: Return geospatial dataset
    GeoEngine->>AI: Run Nearest-Neighbor TSP
    AI-->>API: Optimized route + ETA
    API-->>Client: JSON route plan + cost savings
```
