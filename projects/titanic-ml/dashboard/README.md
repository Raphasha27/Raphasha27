# Titanic ML Dashboard — Streamlit App

[![Streamlit](https://img.shields.io/badge/Streamlit-1.28+-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://streamlit.io)
[![Python](https://img.shields.io/badge/Python-3.10+-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)]

Interactive web dashboard for the Titanic ML model. Predicts survival probability based on passenger features.

## Features

- **Live Predictions** — Input passenger details and get survival probability
- **Feature Importance** — Visualize which features drive predictions
- **Model Comparison** — Compare all trained models side-by-side
- **EDA Viewer** — Browse the training dataset with filters

## Usage

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open http://localhost:8501 in your browser.
